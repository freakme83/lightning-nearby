# Experimental Blitz UI (PR-C)

Developer source selection is shown only when the app URL includes `?lightningDev=1`. Xweather remains the default, and switching to Blitz requires an explicit live check. The browser calls only the Next.js experimental API route; Blitz remains experimental and no production provider migration is part of this change. Empty Blitz results with incomplete coverage are shown as unknown, not clear. No deployment is performed by this PR.
