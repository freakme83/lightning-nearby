# Outer-district generic publication cooldown

An otherwise eligible initial `#ŞİMŞEK` candidate in a recognized Ankara outer district can enter the normal pending publication workflow once per **canonical district** per 30-minute window. An admission in Şereflikoçhisar does not block an independently eligible candidate in Evren; a second Şereflikoçhisar candidate within its own window is suppressed. Profile B promotion, Xweather enrichment, geography, duplicate checks, and the existing publication gates run first. Central Ankara and verified CG (initial, first-CG, and repeat-CG) keep their existing paths. A cooldown denial does not cause another Xweather query.

The worker calls `admit_outer_generic_publication` only for a qualifying outer-district generic candidate whose final ledger decision is `WOULD_PUBLISH`. The service-role-only, invoker-rights function takes one transaction-level advisory lock shared by all outer districts, checks prior **admitted** outer-generic rows with the same canonical district, and inserts the pending publication row in that transaction. The shared lock conservatively serializes concurrent admissions. Its database `recorded_at` is the admission time, not an asserted external X post time. At exactly 30 minutes the previous admission is outside the window. Suppressed, held, duplicate, or failed requests do not reserve or extend a district's window. A missing/failing RPC holds the candidate and does not notify or dispatch it to Telegram or X. The nullable `canonical_district` column marks admitted outer-generic records; existing rows are preserved, and no ambiguous label backfill is attempted.

`outer_district_generic_admitted` identifies fresh admitted rows. `outer_district_generic_cooldown_suppressed` includes incident ID, canonical district, location label, representative coordinates, event count, incident reference time, suppression time, 30-minute duration, expiration, and reason. Ordinary ineligible candidates retain the existing candidate outcome diagnostics. These logs support future analysis only; there is no summary publication path.
